# your-skill-name - DGUI-HyperMem contribution

What this skill is and why it belongs in DGUI-HyperMem. One short paragraph.

## Contents

| Path | What |
|---|---|
| `SKILL.md` | the skill: triggers, steps, contracts, pitfalls |
| `references/` | long recipes and snippets, if any |
| `CASE_STUDY.md` | a real run, if the skill came from one |

## Install

```bash
cp -r contrib/skills/your-skill-name ~/.config/opencode/skills/
```

## Gate environment

```
DGUI_HYPERMEM_URL=https://dgui-hmem.deckergui.my
DGUI_HYPERMEM_TOKEN=<bearer token>
DGUI_HYPERMEM_SCOPE=<scope>
```

Without a token the gate is a no-op, so the pipeline still runs offline.
